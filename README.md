# Portafolio

Mi página personal: quién soy, mis proyectos publicados, experiencia y contacto.

Está hecha con React, TypeScript y Vite, sin librerías de componentes. Todo el texto está en `src/datos.ts`, así que para agregar un proyecto o cambiar algo de la experiencia solo toca editar ese archivo.

## Correrla en local

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```

Se publica en Vercel con cada push a `main`.

## Proyectos que aparecen

- [Cuadre](https://github.com/orlandocastillo-dev/cuadre), finanzas personales
- [Surtido](https://github.com/orlandocastillo-dev/surtido-app), punto de venta para tiendas de barrio
- [MesaTI](https://github.com/orlandocastillo-dev/mesa-ti), mesa de ayuda para soporte técnico
- [Traste](https://github.com/orlandocastillo-dev/traste), letra y acordes para guitarristas
- [Taller Rodada](https://github.com/orlandocastillo-dev/taller-rodada), página de un taller de bicicletas
